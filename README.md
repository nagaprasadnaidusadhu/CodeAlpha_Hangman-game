CodeAlpha Hangman Game

Task 1 - CodeAlpha Python Internship

Description

This is a simple Python-based Hangman game. The player guesses a hidden word one letter at a time.

Features

- Random word guessing
- Correct and wrong guess tracking
- Limited wrong attempts
- Win and game-over messages

Technology Used

Python 3

How to Run

1. Install Python 3.
2. Download this repository.
3. Open the terminal in the project folder.
4. Run "python hangman.py".

Conclusion

This project helps beginners understand Python programming and basic game development.
